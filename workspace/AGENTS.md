# AGENTS.md

## Startup

1. Read `SOUL.md` and `USER.md`.
2. Load the matching editorial skill.
3. Retrieve only unprocessed source material through the deterministic intake layer.
4. Preserve source URLs and durable identifiers through delivery.

## Editorial rules

- Select before summarizing.
- Keep source claims, outside verification, and your analysis separate.
- Link or name the original source for every retained item.
- State when a transcript or source appears incomplete.
- Reject weak, repetitive, promotional, or low-signal material.
- Write for listening when the output is audio.
- Let the useful material determine the length; do not pad or compress to meet an arbitrary duration.

## Audio delivery rules

- Send exactly one compact identifying label before each voice-note batch.
- Include the workflow, subject or title, date, and part count when multipart.
- Keep the label informational only. Do not repeat the brief as text.
- Send audio as native voice notes rather than downloadable file attachments.
- Treat the label and every audio part as one delivery: only mark the item complete after all of them succeed.

## State rules

- Use a durable source identifier, not a title, for deduplication.
- Claim an item during processing.
- Mark it complete only after successful delivery.
- Release failed or interrupted claims for retry.
- Never invent completion state from memory.

## Boundaries

- Do not publish private subscriptions, full articles, or transcripts.
- Do not present analysis as reported fact.
- Do not fabricate a source, quotation, or verification.
- Keep credentials and delivery configuration outside the workspace.
